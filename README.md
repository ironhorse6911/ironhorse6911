# Cyber Citadel AI

A modern full-stack TypeScript application built with TanStack Start, featuring a comprehensive UI component library and real-time database integration.

## 🚀 Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start/) - Modern React meta-framework
- **Frontend**: React 19 with TypeScript
- **Styling**: Tailwind CSS 4 with custom animations
- **UI Components**: Radix UI (comprehensive component library)
- **Routing**: TanStack Router
- **Data Fetching**: TanStack React Query
- **Forms**: React Hook Form with Zod validation
- **Database**: Supabase
- **Build Tool**: Vite
- **Code Quality**: ESLint + Prettier

## 📊 Language Composition

- TypeScript: 96.6%
- CSS: 1.9%
- PLpgSQL: 1.1%
- JavaScript: 0.4%

## ✨ Features

- **Rich UI Components**: Complete set of Radix UI primitives for building accessible interfaces
- **Form Handling**: Type-safe forms with React Hook Form and Zod schema validation
- **Real-time Database**: Supabase integration for scalable backend
- **Responsive Design**: Tailwind CSS for modern, responsive layouts
- **Data Visualization**: Recharts for interactive charts and graphs
- **Modal & Drawer Support**: Dialog and drawer components from Radix UI
- **Accessibility**: Built-in accessibility features through Radix UI

## 📦 Key Dependencies

### UI & Components
- `@radix-ui/*` - Accessible component primitives
- `lucide-react` - Icon library
- `tailwindcss` - Utility-first CSS framework
- `sonner` - Toast notifications

### Forms & Validation
- `react-hook-form` - Performant form handling
- `zod` - TypeScript-first schema validation
- `@hookform/resolvers` - Form resolver integration

### Data & State
- `@tanstack/react-query` - Server state management
- `@supabase/supabase-js` - Supabase client
- `embla-carousel-react` - Carousel component
- `recharts` - Charting library

### Utilities
- `date-fns` - Date utilities
- `clsx` - Class name utilities
- `tailwind-merge` - Merge Tailwind classes
- `vaul` - Drawer component

## 📖 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/ironhorse6911/ironhorse6911.git
   cd ironhorse6911
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:5173` (or the port shown in terminal)
